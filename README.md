# vardamir-rs

A cryptographically verifiable, offline-capable decision ledger 
for autonomous systems operating in denied-network environments.

## What it does

Records every decision made by an autonomous AI system into a 
tamper-evident, hash-chained log. When the system returns from 
offline operation, any third party can verify mathematically that 
the log is intact and was produced by the certified model.
